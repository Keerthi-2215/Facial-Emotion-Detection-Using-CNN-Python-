# Facial Emotion Detection using CNN

## 📌 Description

Facial Emotion Detection is a deep learning-based project that identifies human emotions from facial expressions in images or real-time video. This system uses a Convolutional Neural Network (CNN) to automatically learn facial features and classify them into different emotional categories.

The model is trained on a labeled dataset of facial images representing emotions such as happy, sad, angry, surprise, fear, and neutral. It processes input images by detecting faces, preprocessing them, and then passing them through the trained CNN model to predict the corresponding emotion.

This project demonstrates the application of computer vision and deep learning techniques in real-world scenarios such as human-computer interaction, mental health analysis, and smart surveillance systems.

## 🎯 Objectives

* To build a CNN model for emotion classification
* To accurately detect facial expressions from images or webcam
* To apply image preprocessing techniques for better performance

## 🧠 Technologies Used

* Python
* TensorFlow / Keras
* OpenCV
* NumPy
* Matplotlib

## 🚀 Features

* Real-time emotion detection using webcam
* Image-based emotion prediction
* Face detection and preprocessing
* Multiple emotion classification
